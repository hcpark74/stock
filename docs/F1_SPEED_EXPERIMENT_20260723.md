# F1 속도 실험 결과 (2026-07-23)

## 결론

- 모의투자 운영값 `F1_EXPECTED_QUOTE_CONCURRENCY=1`을 유지한다.
- 동시성 2는 20종목 실측에서 더 느렸고 KIS 호출 제한 응답이 1건 발생했다.
- `KIS_RATE_INTERVAL_SEC`도 모의투자 기본값 1.1초보다 낮추지 않는다.
- 랭킹 등락률로 예상체결가 조회 대상을 줄이는 방안은 가능성이 있지만, 아직 운영에
  적용하지 않는다. 동일 시간대의 추가 shadow 검증이 먼저 필요하다.

운영 설정과 거래 상태는 변경하지 않았으며 주문 API는 호출하지 않았다.

일반화에는 한계가 있지만, 운영값을 높일 근거는 없고 안전성 저하 신호는 확인됐다.

## 다음 승격 조건

사전 필터를 실제 호출 절감 기능으로 승격하려면 다음을 모두 만족해야 한다.

1. 실제 F1 실행 시간대에 최소 10거래일 동안 필터 적용 결과와 전체 조회 결과를 shadow로
   함께 기록한다.
2. 최종 후보 재현율 100%와 일별 후보 누락 0회를 확인한다.
3. KOSPI/KOSDAQ 각각의 호출 수, 완료시간, `RATE_LIMIT_HIT`, 예상체결가 유효 응답률을
   비교한다.
4. 기능은 기본 비활성 환경변수로 추가하고, REAL 전환 전 모의투자에서 별도로 재검증한다.
5. 한 건이라도 최종 후보가 누락되거나 호출 제한이 증가하면 적용하지 않는다.

현재 가장 안전한 개선 순서는 동시성 확대가 아니라 조회 대상 사전 필터의 shadow 검증이다.
