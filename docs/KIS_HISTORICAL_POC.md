# KIS Phase 5 과거 데이터 읽기 전용 PoC

> 검증일: 2026-07-22 15:46 KST  
> 환경: PAPER, 장 종료 후 시세 GET 3회  
> 결론: F1 갭 구간은 공식 일봉으로 재현 가능하지만, 8~10% 조건부 통과와 F1 순위 전체를
> 재현하려면 당시 로컬 F1 스냅샷이 필요하다.

## 1. 안전 범위

`scripts/kis_phase5_historical_poc.py`는 F1 JSONL과 SQLite DB를 읽기 전용으로 열고 집계값만
출력한다. `--with-kis` 사용 시에도 `KIS_MODE=PAPER`, 15:40 이후만 허용하며 공식 일봉 GET을
최대 3회 호출한다. 09:00~09:11, REAL 모드, 인증 실패, HTTP 429, `EGW00201`, 응답 오류나 필드
누락에서는 즉시 중단한다. 주문·정정·취소 경로는 구현하지 않았다.

```powershell
# 로컬 데이터만 검사
python scripts\kis_phase5_historical_poc.py

# 장 종료 후 PAPER 일봉 3표본 대조
python scripts\kis_phase5_historical_poc.py --with-kis --max-kis-samples 3
```

## 2. 공식 API로 확인한 데이터 범위

| 용도 | 공식 API | 확인한 범위 | Phase 5 판정 |
|---|---|---|---|
| 현재 호가·예상체결 | `inquire-asking-price-exp-ccn`, `FHKST01010200` | 현재 종목의 `antc_cnpr`, `antc_vol`, `stck_sdpr` 등. 날짜 파라미터 없음 | 과거 예상체결 복원 불가 |
| 기간별 일봉 | `inquire-daily-itemchartprice`, `FHKST03010100` | 시작·종료일, 일/주/월/년, 1회 최대 100건. 영업일·OHLC·거래량·수정 여부 제공 | 실제 시가 갭과 후행 성과 검증 가능 |
| 최근 일봉 | `inquire-daily-price`, `FHKST01010400` | 최근 30건 | 짧은 보조 조회만 가능 |
| 국내 휴장일 | `chk-holiday`, `CTCA0903R` | 영업일·거래일·개장일 플래그. 원장 서비스 연계로 1일 1회 사용 권고 | PAPER 미지원이므로 대량 백필에 사용하지 않음 |

검토한 공식 샘플:

- [주식현재가 호가/예상체결](https://github.com/koreainvestment/open-trading-api/tree/main/examples_llm/domestic_stock/inquire_asking_price_exp_ccn)
- [국내주식 기간별시세(일/주/월/년)](https://github.com/koreainvestment/open-trading-api/tree/main/examples_llm/domestic_stock/inquire_daily_itemchartprice)
- [국내주식 기간별 시세](https://github.com/koreainvestment/open-trading-api/tree/main/examples_llm/domestic_stock/inquire_daily_price)
- [국내 휴장일조회](https://github.com/koreainvestment/open-trading-api/tree/main/examples_llm/domestic_stock/chk_holiday)

두 일봉 샘플은 수정주가 플래그 `0/1`의 설명이 서로 반대다. 따라서 플래그 의미를 공통 상수로
추정하지 않고 **엔드포인트와 플래그를 한 쌍으로 저장**한다. 이 PoC는
`inquire-daily-itemchartprice` 공식 샘플 설명에 따라 `FID_ORG_ADJ_PRC=0`을 사용했다. 실제
백테스트 승격 전에는 액면분할 등 권리 발생 종목 1건으로 가격 연속성과 `mod_yn`,
`revl_issu_reas`를 별도 검증해야 한다.

## 3. 백테스트 데이터 정의

| 개념 | 저장·계산 기준 | 주의사항 |
|---|---|---|
| 거래일 | 일봉의 `stck_bsop_date`가 존재하는 날짜 | 평일 여부만으로 거래일을 만들지 않는다. |
| F1 관측 시각 | 파일명 시각을 `Asia/Seoul`로 해석 | 현재 레코드에는 시간대가 없어 파일명 계약에 의존한다. 향후 `captured_at` 오프셋 포함 저장이 필요하다. |
| 관측 갭 | 스냅샷의 `gap_pct` 비율 또는 `(expected_price / prev_close) - 1` | 저장 단위는 비율이다. 3%는 `0.03`이다. |
| 일봉 재현 갭 | `(당일 stck_oprc / 직전 거래일 stck_clpr) - 1` | 현재 F1은 09:00 이후 실행되므로 관측 표본에서는 사실상 시가 갭과 일치했다. |
| 코어 | `0.03 <= gap < 0.08` | 8%는 조건부 구간에 포함한다. |
| 조건부 | `0.08 <= gap < 0.10` | 10%는 하드 상한이므로 제외한다. |
| 조건부 통과 | 갭 조건 + 예상체결대금 50억 이상 + `vi_gap >= 0.01` | 일봉만으로 당시 `antc_vol`과 VI 상태를 복원할 수 없다. |
| 장전/당시 기준가 | 스냅샷 `prev_close`; 현재 조회에서는 `stck_sdpr`도 함께 보존 | 권리 발생일에는 단순 전일 종가 대체를 금지한다. |
| 수정주가 | 엔드포인트, 요청 플래그, `mod_yn`, 권리 사유를 함께 저장 | 플래그가 다른 API로 전이되지 않게 한다. |

백테스트는 날짜별 09:00:00~09:10:59 KST의 최초 정상 스냅샷 하나만 사용한다. 주말, DB에서
확인된 `MARKET_CLOSED`, 범위 밖 시각과 동일 날짜 중복은 제외한다. 당시 시점 이후에 생성된 데이터로
후보를 보정하지 않는다.

## 4. 소표본 재현 결과

### F1 스냅샷 품질

- 보유 파일 20개 중 장외 시각 5개, 주말 2개, 확인된 휴장 1개를 제외했다.
- 남은 적격 파일 12개에서 같은 날짜 중복 3개를 제거해 2026-07-09~2026-07-22의 대표 9거래일을
  선택했다.
- 537행에서 JSON 오류 0, 필수 필드 누락 0, 파일 내 중복 종목 0, 갭 산식 불일치 0건이었다.
- 코어 3~8%는 86건, 조건부 8~10%는 16건이었다. 조건부 중 추가 유동성·VI 조건까지 통과한 것은
  1건이며, 전체 `gap_allowed`는 87건이었다.
- 레코드 자체의 타임존·파라미터 버전은 없다. 내용 누락은 없지만 장기 비교의 관측 메타데이터 품질은
  개선이 필요하다.

### 공식 일봉 대조

최근 실제 전략 거래와 같은 날짜·종목이 F1 대표 스냅샷에 있는 3건을 일봉과 대조했다.

| 날짜 | F1 저장 갭 | 공식 시가 갭 | 절대 차이 |
|---|---:|---:|---:|
| 2026-07-22 | 3.380% | 3.378% | 0.002%p |
| 2026-07-16 | 4.320% | 4.322% | 0.002%p |
| 2026-07-15 | 6.440% | 6.438% | 0.002%p |

3건 모두 영업일과 필수 OHLC가 존재했고 평균 절대 차이는 0.002%p였다. 따라서 **현재 09:00 이후
F1의 3~8%/8~10% 갭 구간 판정 자체**는 일봉 시가와 직전 거래일 종가로 재현 가능하다. 다만
API에는 과거 예상체결 조회 날짜가 없으므로 당시 관측값의 원본 증거, 예상체결량·예상체결대금과 VI를
포함한 조건부 통과 및 전체 F1 순위는 로컬 스냅샷 없이는 재현할 수 없다.

## 5. 기존 Improve 메뉴와의 비교

같은 시점의 Improve 집계는 전략 거래 11건(원천 CLOSED 12건 중 수동 1건 제외), MFE 관측 7건
(63.6%), 체결지연 실측 0건, 파라미터 버전 미기록이었다. 후보 공급은 거래일 11일과 순수
`NO_TARGET` 5일, 평가일 16일이다.

두 진단은 대체 관계가 아니다.

- Improve 메뉴는 실제 거래의 손익, MFE, 청산, 주문 슬리피지를 진단한다.
- Phase 5 PoC는 진입 전 후보 모집단 537행의 갭 분포와 데이터 품질을 진단한다.
- F1 임계값 변경은 후보 분포와 실제 거래 성과를 날짜·파라미터 버전으로 연결한 뒤 판단해야 한다.

현 표본에서는 조건부 통과가 1건뿐이고 Improve 전략 거래도 11건이므로 3/8/10% 임계값 변경 근거로는
부족하다. Phase 5의 결론은 “읽기 전용 검증 가능”이며 “파라미터 변경 승인”이 아니다.

## 6. 다음 기록 품질 기준

장기 검증에 사용할 F1 스냅샷에는 다음을 추가한다.

1. `captured_at`을 `+09:00` 오프셋 포함 ISO 8601로 저장한다.
2. F1 임계값·최소 예상체결대금·VI 기준의 `params_version` 또는 설정 스냅샷을 저장한다.
3. `source_endpoint`, TR ID, 시장구분과 가격 조정 플래그를 저장한다.
4. 거래 DB에 선택 당시 `gap_pct`, `gap_band`, F1 점수와 스냅샷 식별자를 연결한다.
5. 백테스트 입력 시 중복·비거래일·권리 발생·필드 누락을 자동 차단하고 제외 사유를 집계한다.
